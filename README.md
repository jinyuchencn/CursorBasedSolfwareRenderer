# 软件渲染器 (CPU)

一个完全基于 CPU 实现的现代特性软件光栅化渲染器。  
无外部依赖，自包含，输出 PPM 图像。

---

## 🤖 关于本项目

> **本项目由 AI (Claude) 生成**  
> 用于帮助学习 AI 辅助编程和图形渲染知识。  
> 通过与 AI 对话的方式，从零开始构建了一个包含现代渲染特性的软件光栅化器。  
> 这是一次探索 AI 编程能力边界的实践，也是学习计算机图形学底层原理的有趣方式。

## 🔧 构建 (Windows PowerShell)

```bash
cmake -S . -B build
cmake --build build --config Release
```

## ▶️ 运行

```bash
./build/Release/software_renderer.exe
```

输出图像：`output.ppm`（在项目根目录）
